# 구독달력

정기 구독료와 한 달 지출을 달마다 보여 주는 아이폰용 앱(PWA)입니다. 구독 결제일은 달력에 표시됩니다. 데이터는 휴대폰에만 저장되고, 서버나 로그인이 없습니다.

## 설치 (아이폰)

1. Safari로 앱 주소를 엽니다.
2. 아래쪽 공유 버튼(네모에 위쪽 화살표) → **홈 화면에 추가** → 추가를 누릅니다.
3. 이제 홈 화면의 **구독달력** 아이콘으로 엽니다. Safari에서 연 화면과 홈 화면 앱은 데이터가 따로 저장될 수 있으니 항상 아이콘으로 여세요.

## 한 달에 한 번: 신한 거래내역 불러오기

1. PC에서 신한은행 인터넷뱅킹에 로그인 → **조회 → 계좌조회 → 예금/신탁** → 통장 [조회]
2. 기간을 고르고 조회 → 오른쪽 위 **[파일 저장]** → 항목 모두 체크 → **[엑셀 저장]** (처음에는 최근 3개월)
3. PC 카카오톡 '나와의 채팅'으로 파일을 보내고, 아이폰에서 파일 열기 → 공유 → **'파일에 저장'**
4. 앱의 지출 탭 → **신한 거래내역 불러오기** → 파일 앱에서 고르기

기간이 겹치게 불러와도 같은 거래는 한 번만 저장됩니다. 계좌번호 같은 머리말 정보는 저장하지 않습니다.

## 구독 등록

- 금액·결제일은 네이버페이 → 결제내역·정기결제, 아이폰 설정 → 이름 → 구독에서 확인할 수 있습니다.
- **통장 표시 이름**은 통장에 찍히는 이름(예: 네이버페이)입니다. 금액·날짜와 함께 통장 거래와 맞춰 보는 데 씁니다. '통장 내역에서 고르기'를 누르면 자동으로 채워집니다.
- 달력 표시: **✓** 통장에서 결제가 확인됨 · **!** 예전엔 확인됐는데 이번 달엔 결제가 안 보임(잔액 부족 등)

## 백업

설정 → **백업 파일 만들기** → '파일에 저장'. 휴대폰을 바꾸면 새 휴대폰에서 설정 → **백업 불러오기**를 누릅니다.

## 개발

- `npm test`: 핵심 로직·파일 불러오기 테스트
- `npm start`: http://localhost:8080 (샘플 데이터: http://localhost:8080/?demo=1)
- `node tools/ui-check.js <폴더>`: 모바일 화면 캡처와 불러오기·저장·오프라인 자동 점검(헤드리스 Edge)
