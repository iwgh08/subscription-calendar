# 구독달력

정기 구독료와 한 달 지출을 달마다 보여 주는 개인용 앱(PWA)입니다. **PC와 아이폰 어디서든 입력·수정**할 수 있고, 두 기기에서 따로 고친 내용은 자동으로 합쳐집니다. 구독 결제일과 직접 적은 일정은 달력에 표시되고, 결제일에 맞춰 그 달 지출에 자동으로 더해집니다. 통장 잔액을 한 번 적어 두면 **지금 통장 잔액**도 계산해서 보여 줍니다.

앱 주소: https://iwgh08.github.io/subscription-calendar/

## 처음 한 번: PC와 폰 연결하기

1. **비공개 저장소 만들기:** github.com → New repository
   - 이름: `subscription-data`
   - **Private**를 고르고 **Add a README file을 체크**한 뒤 Create repository를 누릅니다.
2. **토큰 두 개(PC용·폰용) 만들기:** 프로필 → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token
   - Repository access: Only select repositories → `subscription-data`
   - Expiration: 고를 수 있는 **가장 긴 기간**. 기본값으로 두면 금방 만료됩니다.
   - Repository permissions → Contents → **Read and write**(두 토큰 모두. 폰에서 보기만 할 거면 폰용은 Read-only)
   - 폰을 잃어버리면 폰용 토큰만 지우면 됩니다.
3. **PC:** 앱 주소를 열고 설정 → PC ↔ 폰 연결 → PC용 토큰 붙여 넣기 → **입력·수정** → 연결
4. **아이폰**
   1. Safari로 앱 주소를 열고 공유 → **홈 화면에 추가**를 누릅니다.
   2. 홈 화면의 **구독달력** 아이콘으로 엽니다.
   3. PC 카카오톡 '나와의 채팅'으로 폰용 토큰을 보내 복사하고, 설정 → 붙여 넣기 → **입력·수정** → 연결을 누릅니다.
   4. 카톡 메시지는 지웁니다.

폰에 이미 입력한 구독이 있으면, 3번 전에 폰에서 설정 → 백업 파일 만들기 → PC로 보내기 → PC에서 백업 불러오기를 해 주세요.

## 쓰는 법

- **구독:** 구독 탭 → + 구독 추가. 금액과 결제일은 네이버페이 → 결제내역·정기결제, 아이폰 설정 → 이름 → 구독에서 확인할 수 있습니다.
- **지출·수입:** 내역 탭 위쪽 입력 줄에 날짜·금액·내용을 적고 Enter를 누릅니다.
  - 수입은 입력 줄 맨 앞에서 **수입**을 고른 뒤 적습니다. 하나 넣으면 다시 지출로 돌아옵니다.
  - 구독 결제는 자동으로 더해지니 따로 적지 않습니다.
- **일정:** 달력에서 날짜를 누르고 **+ 이날 일정 추가**. 시간은 비워 두면 하루 종일로 표시됩니다. 일정은 돈 계산에 들어가지 않습니다.
- **지금 통장 잔액:** 홈 → **잔액 입력하기**(다음부터는 **잔액 맞추기**)에 은행 앱에 보이는 지금 잔액을 적습니다.
  - 그 뒤에 적는 수입은 더하고, 지출과 결제일이 된 구독료는 빼서 홈에 보여 줍니다.
  - 오늘 이미 쓰거나 들어온 돈은 **먼저 적은 뒤에** 잔액을 맞춥니다. 맞춘 뒤에 적으면 두 번 계산됩니다.
  - 맞춘 날보다 앞 날짜로 적는 내역은 이미 통장에 반영된 것으로 보고 계산에 넣지 않습니다.
  - 은행 앱과 달라지면 다시 맞추면 됩니다. 맞추기 화면에 앱이 계산한 값이 함께 보입니다.
- **두 기기 맞추기:** 앱을 열거나 다시 화면으로 돌아올 때마다 GitHub과 맞춥니다. 두 기기에서 따로 고쳤으면 항목별로 합쳐지고, 같은 항목을 둘 다 고쳤으면 나중에 맞춘 기기의 내용이 남습니다. 맞추지 못하면 위쪽 줄에 경고가 뜹니다.
- **백업:** 설정 → 백업 파일 만들기 → '파일에 저장'. 토큰은 백업 파일에 들어가지 않습니다.

  - 가짜 GitHub: `/?gh=/__gh`, 토큰 `test-rw` / `test-ro`
- `node tools/ui-check.js <폴더>`: PC·폰 브라우저 두 개로 연결·입력·잔액·일정·받아오기·오프라인·충돌·두 기기 합치기 자동 점검(헤드리스 Edge)
